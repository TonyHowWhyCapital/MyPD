# MyPD

MyPD 是桌面版的資料庫建模工具，可在 macOS 與 Windows 上執行。您可以用它設計資料表、欄位、索引、關聯與關係圖，直接開啟與編輯 PDM 檔案，從資料庫逆向建立模型，再產生 DDL、文件與報表。

MyPD 離線執行。程式不會自動更新，不會回傳任何資料，視窗內的非本機網路請求一律攔截。唯一的例外是新版本檢查：程式啟動時向 GitHub 查詢最新版本號，有新版時在首頁左下角顯示下載連結，不會自動下載或安裝，也不傳送任何專案或使用者資料。取消勾選首頁左下角的「啟動時自動檢查」後，程式完全離線。只有在您自行設定資料庫連線並執行連線相關功能時，Java 引擎才會連到該資料庫。

目前版本：1.2.1。

## 主要功能

### 建模

- **資料表**：欄位、主鍵、替代鍵（唯一約束）、索引、備註。
- **資料域與資料型別**：可重複使用的欄位型別定義，並對應到各種資料庫的實際型別。
- **資料字典**：代碼對照表，可與資料表欄位建立關聯。
- **多表透視**：由多張資料表的欄位組成的 view。
- **主題領域**：把資料表、關係圖與資料字典依業務區塊分組。
- **關係圖**：繪製 ER 圖，設定關聯的基數與更新、刪除時的參照規則。
- **資料表範本**：定義一組預設欄位，建立資料表時套用，之後可以同步到關聯的資料表。
- **模型清單編輯**：以表格跨資料表大量修改資料表、欄位與資料域。

### PDM 檔案

- **直接開啟與編輯**：在首頁開啟 `.pdm` 檔案，儲存時只改寫有變動的部分，其餘內容保持原樣。原始檔案在第一次修改前備份為 `.pdm.bak`。
- **匯入與匯出**：把 PDM 中的資料表、資料域、參照與關係圖匯入專案，或把專案匯出為 PDM 檔案。
- **從資料庫逆向產生 PDM 檔案**：選擇整個資料庫或部分資料表，直接輸出 `.pdm` 檔案。

### 資料庫

- **資料庫連線**：內附 MySQL、Oracle、SQL Server、PostgreSQL、SQLite、DB2 等資料庫的 JDBC 驅動程式，其他資料庫可以指定自訂驅動程式。
- **匯入連線**：從 Navicat（`.ncx`）、DBX（`.json` 或 `dbx.db`）、DBeaver（`data-sources.json`）匯入連線設定。
- **逆向匯入**：讀取資料庫的資料表結構並加入專案，可以選擇資料庫、勾選資料表並指定主題領域。
- **資料庫物件**：觸發程序、預存程序與函式、檢視表、序列、分割區、資料表空間、同義字與權限，可隨 DDL 一起匯出。

### 分析與比較

- **影響分析**：刪除資料表、刪除欄位或修改欄位型別之前，列出受影響的物件，並可儲存分析結果。
- **模型比較與合併**：目前專案、專案檔案、資料庫三者任選兩方比較，勾選差異後產生 ALTER 指令碼，或合併到目前專案。目標是資料庫時，可以確認後把指令碼直接執行到資料庫。
- **版本管理**：記錄模型的版本，產生版本之間的增量 DDL。

### 輸出

- **DDL**：依資料庫類型產生建表、索引與約束語句，範本可以修改。
- **報表**：設計報表範本，從一個或多個模型產生文件式或清單式報表，輸出 Word、HTML、Markdown 或 CSV。文件式報表可以加上封面（含 Logo 與底圖）、頁首、頁碼、章節編號與附頁次的目錄。
- **文件與圖片**：匯出 Word、HTML、Excel 文件，以及關係圖的 PNG 與 SVG。
- **程式碼產生**：依範本產生 Java、MyBatis、C# 等程式碼，範本可以擴充。
- **測試資料**：依資料表、欄位與外鍵關係產生測試資料，輸出 SQL、CSV、Excel 或直接寫入資料庫；規則可以依欄位或資料域設定。

### 介面

- **語言**：繁體中文、簡體中文、English，預設跟隨作業系統。
- **白天與夜間模式**，以及整個介面的縮放。
- **表格**：選擇顯示的欄、拖曳調整順序、多欄排序、最適欄寬、匯出 CSV 與 Excel。

## 從原始碼建置

已在 macOS（Apple 晶片）、Node.js 20、Java 17 下驗證。

```bash
npm install --legacy-peer-deps      # 安裝相依套件
(cd app && npm install)             # 打包時需要的執行期相依套件
npm run build                       # 編譯前端到 app/build
npx electron app                    # 直接執行
npm test                            # 執行自動化測試
```

如果環境變數 `ELECTRON_RUN_AS_NODE` 已設定，執行 `npx electron app` 前請先取消。

### 製作安裝檔

```bash
npm run package-mac                 # dist 下的 dmg（arm64）
npm run package-win                 # dist 下的 Windows 安裝檔（64 位元）
```

安裝檔沒有經過 Apple 公證，也沒有 Windows 的程式碼簽章。使用者第一次開啟時的放行步驟請看 [安裝手冊](docs/安裝手冊.md)。

### Java 引擎

資料庫連線、逆向、Excel 匯入匯出與「匯出為WORD文件」透過 Java 引擎 `pdmaner-java.jar` 執行。這個檔案不在版本庫中，建置前請放到 `public/jar/`，再執行 `npm run build`。沒有這個檔案時，其他功能仍可使用。放入後請執行一次 `python3 scripts/rebrand_java_engine.py public/jar/pdmaner-java.jar`，把引擎內建 Excel 範本的標誌與標題改為 MyPD。

`scripts/java/mypd` 是 MyPD 自己的 Java 小工具，修改後請重新編譯：

```bash
npm run build:javatools
```

### 語言檔

介面文字以 `src/lang/zh.js` 與 `src/lang/ext/*.js` 為來源。修改後請重新產生繁體中文語言檔：

```bash
npm run lang:zhTW
```

## 專案結構

| 路徑 | 內容 |
|------|------|
| `src/app` | 介面：首頁、主視窗、各編輯器與工具 |
| `src/components` | 共用的介面元件 |
| `src/lib` | 資料模型、PDM 讀寫、比較、報表等邏輯 |
| `src/lang` | 語言檔 |
| `src/main.js` | Electron 主程序 |
| `tests` | 自動化測試（Jest） |
| `docs` | 使用文件 |
| `scripts/java` | Java 小工具的原始碼 |
