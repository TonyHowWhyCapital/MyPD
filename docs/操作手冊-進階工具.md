# MyPD 操作手冊：進階工具與參考

適用版本：MyPD 1.0.1（macOS 與 Windows）。

這是操作手冊的第二份，說明快捷工具、其他匯入與匯出、表格共通功能、設定、快捷鍵與常見問題。基本概念、介面與建模流程請看 [MyPD 操作手冊](操作手冊.md)。安裝與 Java 設定請看 [安裝手冊](安裝手冊.md)。

本手冊中以「」標示的文字，是 MyPD 在繁體中文介面上顯示的名稱。箭頭表示選單的層級，例如「快捷工具」→「輸出」→「報表」。

## 7. 快捷工具

工具列的「快捷工具」把工具分成四組：

| 群組 | 工具 |
|------|------|
| 「比較與分析」 | 「模型比較資料庫」、「模型內自訂表比較」、「模型比較與合併」、「影響分析」 |
| 「編輯與管理」 | 「模型清單編輯」、「資料表範本」、「資料庫物件」、「大小寫轉換」 |
| 「輸出」 | 「報表」 |
| 「顯示」 | 「夜間模式」或「白天模式」 |

本節的工具都在對話框中操作。工具中的「儲存」只把修改寫進目前開啟的專案，要寫進磁碟，請再按工具列的「儲存」或 Cmd+S、Ctrl+S。工具中有尚未儲存的修改時，關閉或切換對象前 MyPD 會先詢問是否「放棄未儲存的修改？」。

### 7.1 影響分析

影響分析在您刪除資料表、刪除欄位或修改欄位型別之前，列出會受影響的物件。

1. 按「快捷工具」→「比較與分析」→「影響分析」。
2. 在「新建影響分析」區塊的「操作型別」選擇「刪除資料表」、「刪除欄位」或「修改欄位型別」。
3. 選擇「資料表」。若操作與欄位有關，再選擇「欄位」。
4. 若選「修改欄位型別」，填寫「新資料型別」、「長度」與「小數位」。
5. 按「預覽影響」。

結果表格列出每個受影響的物件，含「物件型別」、「物件」、「所屬」、「原因」、「嚴重程度」與「說明」，表格上方顯示「破壞」、「變更」、「提示」三種嚴重程度的數量。受影響的物件包括外鍵參照、多表透視、索引、關係圖中的節點與關聯線、主題領域、資料庫物件，以及使用相同資料域的欄位。

要保留這次分析：

1. 在結果下方的「分析名稱」輸入名稱。
2. 按「儲存為影響分析」。

儲存的分析列在左側「已儲存的影響分析」，點一下就能重新檢視，按「刪除」移除。這些分析存在專案中，報表也可以輸出它們。

影響分析只預覽，不會真的刪除或修改任何東西。

### 7.2 模型比較與合併

這個工具比較兩個模型，列出差異，並產生 ALTER 指令碼或把差異合併到目前專案。

1. 按「快捷工具」→「比較與分析」→「模型比較與合併」。
2. 在「模型 A」與「模型 B」各選一個來源：
   - 「當前專案」：目前開啟的專案，包含尚未儲存的修改。
   - 「專案檔案」：按「選擇檔案」選擇另一個 `.pdma.json` 專案檔案。
   - 「資料庫」：選擇一個資料庫連線。MyPD 讀取該資料庫目前的結構，需要 Java。
3. 在「被修改的一側(目標)」選擇「修改 A，使其與 B 一致」或「修改 B，使其與 A 一致」。
4. 按「比較」。

差異以樹狀列出，依「表」與「資料庫物件」分類，再細分為「新增」、「刪除」、「修改」，以及「基本資訊」、「欄位」、「索引」。兩邊沒有差異時顯示「兩個模型沒有差異」。

處理差異：

1. 勾選要處理的差異，或勾選「全選」。
2. 選擇處理方式：
   - 「生成 ALTER 指令碼」：顯示把目標改成與來源一致所需的 SQL。
   - 「合併到當前專案」：把勾選的差異套用到目前專案。只有目標一側是「當前專案」時才能使用。合併可能刪除資料表或欄位，MyPD 會先確認。
3. 合併後，畫面顯示「已合併，請儲存專案」。請按「儲存」寫入磁碟。

### 7.3 模型清單編輯

模型清單編輯以表格一次檢視與修改整個專案，適合大量修改欄位名稱、型別或資料域。

1. 按「快捷工具」→「編輯與管理」→「模型清單編輯」。
2. 在上方切換「資料表」、「欄位」或「資料域」。
3. 直接在儲存格中修改。上方的「搜尋」框可以篩選列。
4. 修改後畫面顯示「未儲存」。按「儲存」把修改寫入專案，或按「放棄修改」回到修改前。

三個分頁的內容：

| 分頁 | 欄位 | 可做的事 |
|------|------|----------|
| 「資料表」 | 「程式碼」、「名稱」、「說明」、「欄位數」 | 修改名稱與說明，刪除資料表 |
| 「欄位」 | 「所屬表」、「程式碼」、「名稱」、「資料域」、「型別」、「長度」、「小數」、「主鍵」、「非空」、「自增」等 | 跨所有資料表修改欄位，新增或刪除欄位 |
| 「資料域」 | 「程式碼」、「名稱」、「型別」、「長度」、「小數」 | 修改、新增或刪除資料域 |

使用說明：

- 在「欄位」分頁，按「欄位設定」選擇要顯示的欄位。要新增欄位，先在旁邊的下拉清單選資料表，再按「新增欄位」。
- 在「資料域」儲存格選「＋ 新增資料域…」，可以當場建立資料域並套用到該欄位。選「（不使用資料域）」則取消套用。
- 在「資料域」分頁按「新增資料域」新增一列。仍被欄位使用的資料域不能刪除，MyPD 會顯示「該資料域仍被欄位引用，無法刪除。」
- 刪除資料表時，MyPD 同時處理它在關聯、索引、關係圖與主題領域中的引用。
- 點表頭排序，依次點多個表頭可以多欄排序，點「清除排序」恢復。拖動表頭可以調整欄位順序，點「還原欄位順序」恢復。「最適欄寬」與「還原欄寬」調整欄寬。

按「儲存」只寫入目前開啟的專案。請再按工具列的「儲存」寫入磁碟。

### 7.4 資料庫物件

資料庫物件是資料表以外、要隨 DDL 一起建立的物件。

1. 按「快捷工具」→「編輯與管理」→「資料庫物件」。
2. 左欄依類型篩選：「全部」、「觸發器」、「預存程序/函式」、「視圖(SQL)」、「序列」、「分割區」、「資料表空間」、「同義詞」、「許可權」。
3. 按「新增」，在「型別」選擇物件類型。
4. 填寫「程式碼」、「名稱」、「備註」，視類型選擇「關聯表」並填寫各類型專屬的屬性。觸發器與預存程序還需要在「語句體」輸入 SQL 本體。
5. 若要完全自己寫建立語句，填寫「自訂DDL（非空時替換生成的建立語句）」。
6. 右側選擇「資料庫」，即可預覽該資料庫的 DDL。
7. 按「儲存」。

同一類型中的程式碼不能重複。中欄上方的搜尋框可以依程式碼或名稱篩選。

匯出 DDL 時，「匯出資料表結構DDL」對話框會出現「包含資料庫物件」，勾選後一起匯出。從 PDM 檔案開啟或匯入時，PDM 中的預存程序與視圖會成為資料庫物件。

### 7.5 報表與報表範本設計

報表依範本從一個或多個模型產生文件。報表輸出不需要 Java。

開啟報表工具：按「快捷工具」→「輸出」→「報表」。視窗分成三欄：左欄是「報告範本」清單，中欄是「範本設計」，右欄是「生成報告」。

專案還沒有範本時，清單顯示內建範本，並提示「尚未儲存範本，目前顯示內建範本，儲存或修改後將寫入專案」。

**範本的兩種報告種類。**

- 「文件報告」：由多個章節組成的文件。
- 「清單報告」：只有一個章節，且該章節輸出一張表格。只有清單報告可以輸出 CSV。

**建立與編輯範本。**

1. 在左欄按「新增文件範本」或「新增清單範本」。也可以在現有範本上按「複製」。
2. 在中欄填寫「範本名稱」。
3. 在「章節」選擇章節種類，按「新增章節」。可用的章節有：文字、目錄、模型概要、資料表清單、資料表詳情、欄位清單、索引清單、視圖清單、資料字典、資料域清單、關係清單、資料庫物件、影響分析。
4. 視需要填寫「章節標題」。留空時使用章節種類的名稱。
5. 表格類章節可以點預覽或「版面設計」，開啟「欄位版面設計」。
6. 按「儲存範本」。

章節可以拖曳調整順序，也可以「收合」、「展開」或「移除」。

**欄位版面設計。** 在「欄位版面設計」中：

- 在上方勾選「顯示欄位」，決定表格有哪些欄。
- 點選抬頭或內容，在右側編輯屬性：「顯示名稱」、「順序」、「寬度」、「對齊」、「字型大小」、「字型」、「文字顏色」、「底色」與粗體、斜體、底線。
- 拖曳抬頭調整欄的順序，拖曳分隔線調整寬度。
- 「字型與顏色套用到所有欄位」把目前的樣式套用到全部欄。
- Cmd+Z 或 Ctrl+Z 復原，Cmd+Y 或 Ctrl+Y 重做。

**產生報告。**

1. 在右欄的「包含的模型」中，「目前專案」一定會包含。要合併其他專案，按「新增模型檔案」選擇 `.pdma.json` 檔案。
2. 在「輸出格式」選擇格式：

| 格式 | 保留的樣式 |
|------|------------|
| 「Word 文件 (.docx)」 | 欄寬、對齊、字型與顏色 |
| 「網頁 (.html)」 | 欄寬、對齊、字型與顏色 |
| 「Markdown (.md)」 | 只保留對齊 |
| 「CSV (.csv)」 | 純資料，只有清單報告可用 |

3. 按「預覽」檢視結果。Word 與網頁格式的預覽中可以拖曳抬頭分隔線調整欄寬，點對齊圖示切換對齊，儲存範本後保留。預覽只顯示前幾筆資料。
4. 按「匯出」，MyPD 以範本名稱產生檔案。

範本存在專案中，修改後請儲存專案。

### 7.6 資料表範本

資料表範本是一組預設欄位，例如每張表都要有的建立人、建立時間欄位。

建立範本：

1. 按「快捷工具」→「編輯與管理」→「資料表範本」。
2. 按「新增範本」。或在「選擇資料表」選一張現有的表，按「從已有表建立」，以那張表的欄位為起點。
3. 填寫「範本程式碼」與「範本名稱」，視需要填寫「備註」。
4. 在「預設欄位」按「新增欄位」，填寫每個欄位的程式碼、名稱、「資料域」或「資料型別」、「長度」、「小數位」、「主鍵」與「非空」。
5. 按「儲存範本」。

範本程式碼不能空白，也不能重複。同一個範本中的欄位程式碼也不能重複。

使用範本：建立資料表時，在「新建型別」選「從範本建立」，再選範本。勾選「保持與範本的關聯」，這張表就會出現在範本的「關聯的資料表」清單中。

同步範本：修改範本後，按「同步關聯的表」。MyPD 先提示會覆蓋幾張關聯資料表的欄位，確認後才同步。

刪除範本時，關聯的資料表保留目前的欄位，只解除關聯。

### 7.7 其他工具

**模型比較資料庫。** 這個項目切換到「版本管理」頁籤的「資料庫比較」，比較模型與資料庫的實際結構。需要 Java。

**模型內自訂表比較。** 在同一個專案中，以「比較清單」比較指定的資料表。按「新增行」逐列選取要比較的表。「儲存比較清單」與「載入比較清單」把清單存成檔案或讀回來。

**大小寫轉換。** 一次轉換整個專案的英文大小寫。對話框中可以分別為「表名」、「欄位名」、「索引名」與「資料型別」選擇「全部大寫」或「全部小寫」，按「確定」套用。

**操作歷史。** 工具列的「操作歷史」列出每次儲存時留下的快照，最新的在最上方。每一筆有四個操作：

- 「新視窗開啟」：在新視窗以唯讀模式開啟這份快照。
- 「詳細日誌」：顯示這份快照與前一份之間的變更。
- 「恢復」：用這份快照取代目前專案。這個操作會覆蓋目前專案的內容。恢復後請儲存專案。
- 「刪除」：刪除這份快照檔案。

## 8. 其他匯入與匯出

### 8.1 匯入

「匯入」選單的項目：

| 選單路徑 | 用途 | 需要 Java |
|----------|------|-----------|
| 「從PDManer歷史版本檔案中匯入」→「從PDMan檔案」、「從CHNR檔案」、「從PDManer檔案」 | 匯入 `.pdman.json`、`.chnr.json`、`.pdma.json` 中的資料表 | 否 |
| 「從其他模型檔案中匯入」→「從PowerDesigner檔案」 | 匯入 PDM，請看主手冊 5.3 節 | 否 |
| 「從其他模型檔案中匯入」→「從EXCEL檔案」 | 依 Excel 範本匯入資料表 | 是 |
| 「從資料庫逆向匯入」→「從資料庫連線逆向解析」 | 請看主手冊 4.3 節 | 是 |
| 「從資料庫逆向匯入」→「從資料庫逆向生成 PDM 檔案」 | 請看主手冊 4.4 節 | 是 |
| 「從資料庫逆向匯入」→「從DDL檔案逆向解析」 | 從 `.sql`、`.txt` 或 `.ddl` 檔案中的建表語句建立資料表 | 是 |
| 「從JSON中匯入專案設定」→「匯入型別設定」、「匯入程式碼生成器」、「匯入系統設定」 | 匯入從其他專案匯出的設定 | 否 |
| 「從JSON中匯入專案資料」→「匯入資料字典」 | 匯入資料字典 | 否 |

從 Excel 匯入時，對話框提供「簡單範本下載」與「主題分組式範本下載」兩種範本。依範本填好後，按「選擇EXCEL檔案並匯入」。檔案必須是 `.xlsx`。

除了 JSON 設定類的項目，其他匯入都會先列出檔案中的資料表，讓您勾選並指定主題領域，按「確定」後才加入專案。

### 8.2 匯出

「匯出」選單的項目：

| 選單路徑 | 輸出 | 需要 Java |
|----------|------|-----------|
| 「匯出文件」→「匯出為WORD文件」 | Word 文件，含關係圖圖片 | 是 |
| 「匯出文件」→「匯出HTML文件」 | 單一 HTML 檔案，含關係圖 | 否 |
| 「匯出文件」→「匯出EXCEL文件」 | Excel 活頁簿 | 是 |
| 「匯出文件」→「匯出為PowerDesigner檔案(.pdm)」 | PDM 檔案，請看主手冊 5.4 節 | 否 |
| 「匯出SQL」→「匯出資料表結構DDL」 | DDL，請看主手冊 6.2 節 | 否 |
| 「匯出SQL」→「匯出資料字典SQL」 | 資料字典的 SQL | 否 |
| 「匯出當前畫布」→「匯出為PNG圖片」、「匯出為SVG檔案」 | 目前關係圖的圖片 | 否 |
| 「匯出本專案設定為JSON」→「匯出型別設定」、「匯出程式碼生成器」、「匯出系統設定」 | 設定的 JSON 檔案 | 否 |
| 「匯出本專案資料為JSON」→「匯出資料字典」 | 資料字典的 JSON 檔案 | 否 |

**Word 文件。** 對話框中選擇「全部匯出」或「篩選匯出」。選「篩選匯出」時可以勾選要包含的資料表。「文件範本設定」可以指定自己的 `.docx` 範本，「下載文件範本」取得內建範本作為修改的起點。MyPD 會先把每張關係圖產生成圖片，再產生 Word 文件。

**關係圖圖片。** 「匯出當前畫布」只在目前頁籤是關係圖時可用。也可以在模型樹的關係圖上按右鍵，選「匯出為PNG」或「匯出為SVG」。

如果需要可以自訂章節與欄位的文件，請改用 7.5 節的報表工具，它也能輸出 Word、HTML 與 Markdown。

## 9. 表格共通功能

資料表的欄位清單、模型清單編輯、匯入連線清單等表格，有一組共通的功能。表格上方或表頭的提示文字會說明可用的操作。

| 功能 | 操作 |
|------|------|
| 選擇顯示的欄 | 點「顯示欄位」，勾選或取消勾選欄。點「還原欄位」恢復預設 |
| 調整欄的順序 | 拖動表頭到新的位置 |
| 排序 | 點表頭的排序符號，依序切換遞增、遞減、不排序。依次點多欄就是多欄排序，符號旁的數字是排序順位。點「清除排序」取消 |
| 調整欄寬 | 拖動表頭右緣。在右緣連按兩下設為最適欄寬 |
| 全部最適欄寬 | 點「最適欄寬」。點「還原欄寬」恢復預設 |

排序後，正在編輯的列不會因為內容改變而跳走，直到您改變排序條件。下拉清單的寬度會跟著欄寬。欄的顯示、順序與欄寬記在這台電腦上，每個表格各自記住，不會寫進專案檔案。

資料表的欄位清單上方另有「匯出 CSV」與「匯出 Excel」，可以把欄位清單匯出成檔案。有選取的列時只匯出選取的列，沒有選取時匯出全部。

## 12. 已知限制與常見問題

**按了連線「測試」或逆向，出現找不到 JDK 的訊息。** 訊息以「未檢測到JDK」開頭時，表示 MyPD 找不到 Java。請安裝 Java，或到「設定」→「系統引數」→「JAVA_HOME」指定 Java 目錄，再按「測試」確認。詳細步驟請看 [安裝手冊](安裝手冊.md)。

**訊息以「未找到Java引擎檔案」開頭。** 安裝包缺少 Java 引擎檔案 `pdmaner-java.jar`。這不是您的設定問題，請回報給提供安裝包的人。

**逆向大型資料庫時出現記憶體不足。** 訊息會提示到「JVM引數」調整。請在「設定」→「系統引數」→「JVM引數」提高記憶體上限。

**錯誤訊息中提到日誌檔案。** 連線與逆向失敗時，對話框會顯示日誌資料夾的位置，可以點連結開啟。

**PDM 檔案儲存後，資料字典或多表透視不見了。** PDM 檔案不保存這些內容，請看主手冊 5.2 節。編輯 PDM 時若加入了這類內容，請用「另存為」存成 `.pdma.json`。

**PDM 檔案沒有自動儲存。** 自動儲存刻意不寫回 PDM 檔案，請手動按「儲存」。

**DBX 匯入的連線沒有密碼。** DBX 的密碼已加密，無法讀取。請在「資料庫連線配置」自行填寫。

**連線匯入清單中有些項目不能選。** 標示「（不支援）」的連線，其資料庫類型 MyPD 不支援。

**逆向時看不到「資料庫」下拉清單。** 只有 MySQL、MariaDB、PostgreSQL 與 SQL Server 的連線可以選擇資料庫。其他資料庫請在連線的 url 中指定。

**「模型比較與合併」的連線清單看不懂。** 這個下拉清單顯示的是連線的內部代碼，不是連線名稱。清單的順序與「資料庫連線配置」中的連線順序相同，預設選取第一個連線。

**「模型比較與合併」或報表無法讀取 PDM 檔案。** 這兩個工具的「選擇檔案」與「新增模型檔案」只能讀取 JSON 格式的專案檔案。請先開啟 PDM，「另存為」`.pdma.json` 後再比較。

**參考範本不能使用版本管理。** MyPD 會顯示「參考案例無法使用版本管理功能，請先執行儲存操作！」。請先把範本另存為專案檔案。

**以唯讀模式開啟後看不到工具列。** 唯讀模式會隱藏工具列與「版本管理」頁籤。請關閉專案，再從首頁正常開啟。

**誤刪或改壞了模型，想回到之前的狀態。** 使用工具列的「操作歷史」，選一份儲存時的快照「恢復」，再儲存專案。若是 PDM 檔案，原始內容在同目錄的 `.pdm.bak` 中。

**MyPD 當掉後，專案資料還在嗎？** 視窗當掉或沒有回應時，MyPD 會在專案資料夾寫出 `<專案名>-backup-<時間>.chnr.json`。這是一般的專案檔案，可以從首頁「開啟」。
